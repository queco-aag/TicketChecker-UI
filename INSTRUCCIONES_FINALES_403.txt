📊 COMPARACIÓN: ANTES vs DESPUÉS

ANTES (Token sin roles):
┌─────────────────────────────────────────────────────────────┐
│ Token JWT:                                                  │
│ {                                                           │
│   "sub": "admin",                                           │
│   "iat": 1774868697,                                        │

│   // ❌ NO hay roles                                        │
│ }                                                           │
│                                                             │
│ Resultado:                                                  │
│ POST /api/v1/premios                                        │
│ Status: 403 Forbidden ❌                                    │
└─────────────────────────────────────────────────────────────┘

DESPUÉS (Token con roles):
┌─────────────────────────────────────────────────────────────┐
│ Token JWT:                                                  │
│ {                                                           │
│   "roles": ["ROLE_ADMIN"],  // ✅ Roles incluidos          │
│   "sub": "admin",                                           │
│   "iat": 1774868697,                                        │
│   "exp": 1774955097                                         │
│ }                                                           │
│                                                             │
│ Resultado:                                                  │
│ POST /api/v1/premios                                        │
│ Status: 201 Created ✅                                      │
└─────────────────────────────────────────────────────────────┘
