    @RequestParam String nombre,          // ← Obligatorio

    @RequestParam(required = false) MultipartFile imagen) {
    ...
}

El backend espera recibir datos como FORM DATA, no JSON.

✅ SOLUCIÓN APLICADA
═══════════════════════════════════════════════════════════════

Archivo: src/shared/api/client.js

ANTES (enviaba JSON):
─────────────────────────────────────────────────────────────
crearPremio: (premio) =>
  api.post('/premios', premio, { requiresAuth: true })

// Esto enviaba:
// Content-Type: application/json
// Body: {"nombre":"...","descripcion":"...","anio":2026}


AHORA (envía FormData):
─────────────────────────────────────────────────────────────
crearPremio: (premio) => {
  const formData = new FormData();
  formData.append('anio', premio.anio);
  formData.append('nombre', premio.nombre);
  if (premio.descripcion) {
    formData.append('descripcion', premio.descripcion);
  }
  if (premio.imagen) {
    formData.append('imagen', premio.imagen);
  }
  return api.post('/premios', formData, {
    requiresAuth: true,
    headers: { 'Content-Type': 'multipart/form-data' }
  });
}

// Esto envía:
// Content-Type: multipart/form-data; boundary=----...
// Body: FormData con los campos

═══════════════════════════════════════════════════════════════
📝 NOTA IMPORTANTE: URL FOTO vs IMAGEN
═══════════════════════════════════════════════════════════════

El backend acepta 2 formas de agregar imagen al premio:

1. URL Foto (urlFoto):
   • Campo de texto en el frontend
   • Enlace a una imagen externa
   • Se guarda como texto en la BD

2. Imagen (imagen):
   • Archivo subido desde el frontend
   • Se guarda en el servidor
   • El backend genera la URL automáticamente

ACTUALMENTE el formulario usa "urlFoto" (campo de texto).
Si quieres permitir subir imágenes, necesitas:
  • Agregar un campo <input type="file"> en el formulario
  • Pasar el archivo en premio.imagen
