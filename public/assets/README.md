# ASPADIF Logo Placeholder

This file serves as a placeholder for the ASPADIF logo.

To add the actual logo:
1. Download the logo from: http://www.aspadif.org/photogallery/logos/
2. Save it as `logo-aspadif.png` in this directory
3. Delete this README file

The logo should be in PNG format with transparent background, optimally sized at around 200x80 pixels for best display in the header.
