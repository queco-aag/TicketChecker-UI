🚀 PASOS SIGUIENTES
═══════════════════════════════════════════════════════════════

PASO 1️⃣ : CONFIGURAR CORS EN EL BACKEND
─────────────────────────────────────────────────────────────

Ir al proyecto del backend:
  cd C:\Workspace\Particular\TicketChecker

Opción A - Spring Boot (WebConfig):
  Crear: src/main/java/com/aspadif/ticketchecker/config/WebConfig.java

  @Configuration
  public class WebConfig implements WebMvcConfigurer {
      @Override
      public void addCorsMappings(CorsRegistry registry) {
          registry.addMapping("/api/**")
                  .allowedOrigins("http://localhost:5173", "http://localhost:3000")
                  .allowedMethods("GET", "POST", "PUT", "DELETE", "PATCH", "OPTIONS")
                  .allowedHeaders("*")
                  .allowCredentials(true)
                  .maxAge(3600);
      }
  }

Opción B - Spring Security:
  Modificar SecurityConfig.java (ver CONFIGURACION_CORS_BACKEND.md)

═══════════════════════════════════════════════════════════════
🔍 VERIFICAR QUE CORS FUNCIONA
═══════════════════════════════════════════════════════════════

Desde PowerShell, probar el endpoint OPTIONS (preflight):

  curl -X OPTIONS http://localhost:8080/api/v1/premios `
    -H "Origin: http://localhost:5173" `
    -H "Access-Control-Request-Method: POST" `
    -v

DEBE RESPONDER CON:
  Access-Control-Allow-Origin: http://localhost:5173
  Access-Control-Allow-Methods: GET, POST, PUT, DELETE, ...


═══════════════════════════════════════════════════════════════
❌ SI SIGUE DANDO 403 (Forbidden)
═══════════════════════════════════════════════════════════════

Posibles causas:

1. CORS no está configurado en el backend
   → Ver CONFIGURACION_CORS_BACKEND.md

2. El endpoint POST /premios no existe en el backend
   → Verificar que esté implementado

3. El usuario no tiene rol ADMIN
   → Verificar en los logs del backend:
     • Token válido: true/false
     • Usuario extraído del token
     • Roles del usuario

4. El token JWT no es válido
   → Verificar clave secreta del JWT en backend y frontend

5. Spring Security está bloqueando la petición
   → Verificar configuración de Security
   → Asegurarse de que /api/v1/premios permite ROLE_ADMIN
