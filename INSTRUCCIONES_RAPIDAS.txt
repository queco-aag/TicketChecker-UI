PASO 1️⃣ : REINICIAR EL SERVIDOR DE VITE
─────────────────────────────────────────────────────────────

Si el servidor está corriendo:
  1. Presiona: Ctrl + C  (en la terminal donde corre npm run dev)

Luego ejecuta:

  npm run dev


PASO 2️⃣ : LIMPIAR LA CACHÉ DEL NAVEGADOR
─────────────────────────────────────────────────────────────

OPCIÓN A (Más rápida - RECOMENDADA):

  • Abre una ventana de incógnito/privada:

    Ctrl + Shift + N  (Chrome/Edge)
    Ctrl + Shift + P  (Firefox)

  • Ve a: http://localhost:5173


OPCIÓN B (Limpiar localStorage):

  • Abre el navegador normal
  • Presiona F12 (abrir DevTools)
  • Ve a la pestaña "Console"
  • Ejecuta:

    localStorage.clear();
    location.reload();


PASO 3️⃣ : HACER LOGIN CON LA CONSOLA ABIERTA
─────────────────────────────────────────────────────────────

IMPORTANTE: Debes tener F12 abierto ANTES de hacer login

  1. Presiona F12 para abrir DevTools
  2. Ve a la pestaña "Console"
  3. Haz clic en "Login" en la página
  4. Ingresa tus credenciales
  5. Haz clic en "Iniciar Sesión"
  6. OBSERVA LA CONSOLA

❌ POSIBLES PROBLEMAS Y SOLUCIONES

═══════════════════════════════════════════════════════════════


PROBLEMA: Sigo viendo errores CORS
─────────────────────────────────────────────────────────────

SOLUCIÓN:

  1. Detén el servidor (Ctrl + C)

  2. Ejecuta:
     Remove-Item -Path node_modules\.vite -Recurse -Force
     npm run dev

  3. Recarga la página con: Ctrl + F5


PROBLEMA: Veo "Token extraído: undefined"
─────────────────────────────────────────────────────────────

CAUSA: El backend NO está devolviendo el token

SOLUCIÓN:

  1. Ve a F12 → Network
  2. Busca: POST /api/v1/auth/login
  3. Haz clic → Pestaña "Response"
  4. Copia la respuesta completa
  5. Compártela para revisarla


PROBLEMA: La URL de login es http://localhost:8080/...
─────────────────────────────────────────────────────────────

CAUSA: El proxy no se está usando

SOLUCIÓN:

  1. Verifica que vite.config.js tiene el proxy configurado
  2. Reinicia el servidor completamente
  3. Usa modo incógnito


PROBLEMA: Error 401 "Credenciales inválidas"
─────────────────────────────────────────────────────────────

CAUSA: Usuario o contraseña incorrectos

SOLUCIÓN: Verifica las credenciales correctas del backend
